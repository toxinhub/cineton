# সিনেমা ডায়েরি — সেটআপ
1. GitHub-এ নতুন রিপো বানান, এই তিনটি ফাইল (index.html, admin.html, data.json) আপলোড করুন।
2. Settings → Pages → Branch: main / root → Save। সাইট: https://USERNAME.github.io/REPO/
3. TMDB (themoviedb.org/settings/api) ও OMDb (omdbapi.com/apikey.aspx) থেকে ফ্রি API key নিন।
4. GitHub → Settings → Developer settings → Fine-grained tokens: শুধু এই রিপো, Permission: Contents = Read and write।
5. /admin.html খুলে রিপো (username/repo), টোকেন ও দুটি key দিন → "সংরক্ষণ ও ডেটা লোড"।
